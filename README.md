# snowbot
A bot tweeting daily snow information.

X - https://x.com/TromsoSnow
Bluesky - https://bsky.app/profile/tromsosnow.bsky.social

Utilises the Frost API from the Norwegian Meteorologisk Institutt https://frost.met.no/index.html to obtain snow data.

As well as daily stats on the changing snow depth and snowfall, monthly stats are published on the first of each month.
